# The Meltdown Room release history

App release numbers and the Devvit SDK version are separate.

## 0.0.13 — complete return-experience update

Published publicly and installed in r/TheMeltdownRoom, verified against Reddit's developer API on October 17, 2026.

- Main-page Unwind, Play and favorite-room choices; full Property Map retained.
- Device-local favorite, last-room shortcut and returning companion greeting.
- Archery Target Trail, separate mode personal bests, and neutral Reset aim.
- Distinct modern room layouts, compact glass-and-gold controls, animated scenery and reduced-motion support.
- Three modern activities: archery, balloon garden and paper toss.
- Accessible button labels, delegated actions compatible with Reddit’s script policy, external navigation bridge and phone-layout fixes.
- Public README rewritten for visitors. Technical setup moved to MAINTAINERS.md.
- Devvit SDK dependencies remain pinned to 0.14.8.

## 0.0.12 — modern rooms submission

Submitted successfully to Reddit on October 17, 2026. Public visibility subsequently confirmed through Reddit's developer API. Superseded by 0.0.13.

## 0.0.11 — earlier public release

Updates the existing sunshine7933/Meltdown-room website. Preserves the existing personal story, social links, resource shelf and account integration.
