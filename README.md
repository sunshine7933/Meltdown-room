# The Meltdown Room website

The public website for The Meltdown Room is https://themeltdownroom.com/.

The homepage links to the interactive experience at app-fixed.html and the playable Reddit post in r/TheMeltdownRoom.

The October 17, 2026 website update brings the modern gold-and-glass rooms, moving scenery, companion, optional favorite/continue shortcuts and modern activities to the website. It preserves the existing story, social links, resource shelf and optional website account integration.

The public website also has a continuous lake backdrop, champagne-gold glass controls, a six-topic support collection, simplified navigation and a two-choice opening. Scene motion respects the pause control, reduced-motion preferences and page visibility. The founder story and existing resources are preserved.

The website and Reddit release are separate deployments. Reddit app 0.0.13 is public and installed in r/TheMeltdownRoom, verified October 17, 2026; Devvit SDK dependencies are 0.14.8. See CHANGELOG.md for release history and verification status.

Website notes are local unless a signed-in visitor explicitly uses the existing cloud-backup controls. Other users of the same device may be able to access browser storage. No new account backend or database schema was introduced by this update.
