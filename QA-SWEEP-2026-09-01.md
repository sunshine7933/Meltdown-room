## Founder confirmation — Memorial Room

On 2026-09-01, Sunshine explicitly reconfirmed that **Memorial Room is intended to be its own dedicated room/experience**, not only a Memorial Shelf inside Reflection Library. This is now treated as a Founder-Locked product requirement.

The older build already stored six private memorial entries inside `meltdownReflectionLibrary.memorial`. The QA wrapper now adds a standalone `#memorial` screen and reuses that exact storage so existing memorial writing is preserved rather than migrated or discarded.

No dedicated Founder-Locked Memorial Room scene image was found by filename/title in the recovered assets. Therefore this QA implementation deliberately uses a restrained rustic functional shell instead of inventing or falsely labeling new scene artwork as Founder-Locked. A specific Memorial scene visual can be recovered or founder-approved separately.

## Fixed on this QA branch

### 1. Global navigation now respects the app lifecycle

`app-fixed.html` previously changed `.active` screen classes directly from its injected Back / Great Room / Home navigation. The QA branch now calls the inner app's `showScreen(id)` whenever possible and safely falls back to screen activation if a dynamically added QA screen is not recognized.

### 2. Back history loop protection

The wrapper suppresses re-adding a screen to history while navigating backward, reducing the chance of a Back-button loop.

### 3. Property Map uses the approved recovered map

If the dedicated Property Map is still pointing to `home.png`, the QA wrapper replaces only that map image at runtime with:

`founder-locked-assets/living-property-map.png`

This is a targeted functional repair using an existing Founder-Locked asset, not a redesign.

### 4. Small controls receive a minimum touch target

Hotspot-style buttons receive a minimum 44x44px touch target in the QA wrapper without resizing or replacing the underlying Founder-Locked artwork.

### 5. Icon-only control accessibility

Icon-only buttons/role-buttons that lack an accessible label receive a fallback label.

### 6. Escape key navigation

Escape closes the Memorial editor first when it is open; otherwise it routes through app-aware Great Room navigation.

### 7. Static deployment cleanup

`.assetsignore` excludes internal/stale files from the Cloudflare static asset bundle, including the master handoff/checklist, QA reports, the very large legacy v0.1 HTML, old index file, and malformed duplicate index filename. Runtime assets and Founder-Locked visual assets remain available.

### 8. Dedicated Memorial Room

The QA wrapper now creates a dedicated `#memorial` room with:

- six private memorial-memory cards
- private save/edit/delete behavior
- reuse of the existing `meltdownReflectionLibrary.memorial` data
- a clear Memorial entry in global navigation
- Reflection Library, Great Room and Home exits
- existing Reflection Library Memorial Shelf buttons redirected into the matching Memorial Room memory slot
- no deletion of the old shelf/data, preserving backward compatibility
- Still Mode-compatible candle treatment and mobile touch sizing

## Asset findings

The repository contains multiple zero-byte image placeholders in `founder-locked-assets/` plus zero-byte root PNGs such as `meltdown-room.png` and `thinking-room.png`. They must not be treated as valid images.

The current runtime is less affected than the raw file list suggests because several rooms use valid JPG files, embedded image data, or other recovered PNGs. The wrapper also retains targeted JPG fallbacks for known zero-byte PNG names.

Do NOT bulk-delete or replace Founder-Locked placeholders until each one is mapped to its approved source/reference.
